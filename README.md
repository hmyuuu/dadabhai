# Dadabhai

A smiling plush companion for Codex, with 9 animations and 16 look directions.

![Dadabhai](previews/waving.gif)

## Install

From this repository’s root:

```sh
pet_dir="${CODEX_HOME:-$HOME/.codex}/pets/dadabhai"
mkdir -p "$pet_dir"
cp pet.json spritesheet.webp "$pet_dir/"
```

Codex v2 · 1536 × 2288 WebP · 192 × 208 cells.
